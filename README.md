# hichokai-web
箏曲部飛鳥会の公式Website

## 背景・概要
現状：部の情報がまとまった場所がなくわかりにくい(InstagramとTwitterのみ)
旧サイト：Wixで作られたもの。2017年から使われていたようだが2019年を最後に更新が止まっている

目的：集客、新入生向けの部の紹介、後輩へ引き継げる仕組み
重視する点：検索で見つかる、部にまつわる情報が一か所でみられる、HTMLをかけない部員でも管理画面から更新できる

## 主な機能
フェーズ1（2027年3月上旬公開目標）
トップ：次のイベント、ひとこと紹介、SNSリンク
飛鳥会とは：箏・三味線の紹介、活動日、雰囲気、初心者歓迎
演奏会：今後の予定、過去の公演（曲目・写真）
新歓・よくある質問
お問い合わせ：部のGmail・Instagramへの案内
所蔵楽譜検索（余裕があれば）：誰でも検索でき、楽譜ごとに個別ページ
フェーズ2（ミニコン後〜2027年夏）
管理画面：部員がログインして、お知らせ・公演・楽譜を追加。権限を分ける
演奏記録と動画：楽譜ページに演奏歴、YouTube動画があれば埋め込み
お問い合わせフォーム：部のGmailに通知

## データ構造（案）（表にすると見やすい）

楽譜：曲名、読み仮名、作曲者、編成（箏・十七絃・三味線など）、備考
演奏会：名前、日付、場所
演奏記録：演奏会、楽譜、YouTube動画URL（任意）
ポイント
演奏記録で楽譜と演奏会をつなぎ、演奏会の曲目から楽譜ページへリンク
同じ曲でも演奏会ごとに動画が違うので、動画は演奏記録に持たせる
読み仮名があると、ひらがなでも検索できる

## 方針

楽譜の画像・PDFは公開しない（著作権のため）。公開は曲名・作曲者・編成・演奏歴のみ
来場予約機能は作らない
楽譜ごとに専用URLとページタイトルを付け、サイトマップを作ってGoogle Search Consoleに登録
部員の写真・個人情報は掲載許可を得たものだけ
パスワードなどはコミットせず .env で管理
